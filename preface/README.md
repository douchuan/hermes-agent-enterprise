AI 正在从能够回答问题的工具，逐渐发展为能够调用工具、执行任务，并在一定程度上积累工作经验的智能体（Agent）。随着这些能力进入企业环境，一个新的问题随之出现：如何让 AI Agent 不仅能够运行，还能够在真实的业务场景中长期、可靠地工作？

这并不是简单地安装一个 Agent 就能解决的问题。

企业有自己的身份体系、业务系统、数据边界和管理要求。Agent 一旦需要访问企业数据、调用内部 API、执行实际业务操作，就会面临新的挑战。它需要什么权限，能够访问哪些资源，如何隔离不同员工的 Agent，如何管理持久化的记忆与技能，以及如何发现和追踪异常行为，都需要在系统设计阶段认真考虑。

这正是我开始研究 Hermes Agent 企业部署的原因。

Hermes Agent 为这项研究提供了一个具体的对象。它具备工具调用、记忆管理和技能机制，也支持多种运行方式。围绕它展开研究，可以将 AI Agent 的运行机制与企业实际需要的基础设施联系起来，进一步分析个人级 Agent 与企业级服务之间的差距。

本书不会只介绍如何安装和配置 Hermes，也不会将安全问题简化为一组孤立的技术措施。我更希望从整体架构出发，讨论企业如何管理 Agent 的身份与权限，如何控制 Agent 对企业系统和外部服务的访问，如何处理凭证、记忆和技能，以及如何通过可观测性和审计机制，让 Agent 的运行过程更加透明、可控。

在此基础上，本书也关注一个更长远的问题：当越来越多的员工开始使用 AI Agent 时，企业如何在保护个人数据与权限边界的前提下，让经过验证的工作方法得到复用，并逐步形成组织层面的能力。

本书以 Hermes Agent 为主要研究对象，面向希望理解 AI Agent 企业部署、平台架构与安全治理的技术人员和架构师。书中将结合架构设计、机制分析和配套实验，说明关键设计为什么必要、有哪些实现方式，以及这些方式各自面临什么限制。对于尚未经过完整生产环境验证的设计，也会尽可能明确区分参考架构、实验实现与实际部署经验。

希望这本书能够帮助读者建立一套分析和设计企业级 AI Agent 平台的思路，而不仅仅是获得一份可以照着执行的部署步骤。

个人级 Agent 关注的是如何帮助一个人更好地完成工作；企业级 Agent 则需要进一步回答，如何让这种能力在明确的责任、权限和治理边界内，可靠地服务于企业业务。

这也是本书希望与读者共同探索的问题。
