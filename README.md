# Hermes Agent 企业部署实践

本书探索如何在企业环境中安全地部署和运行 [Hermes Agent](https://github.com/NousResearch/hermes-agent)，为员工提供个人 AI Agent，并让它在明确的权限和安全边界内访问企业系统。

当 AI Agent 开始代表员工调用 API、处理业务数据和执行任务时，仅仅运行一个 Agent 并不够。企业还需要解决身份认证、运行环境隔离、网络访问控制、凭证管理、高风险操作审批，以及全链路审计等问题。

本书将围绕这些实际问题，逐步构建一套面向企业场景的参考架构，并通过配套代码和实验展示关键机制的实现与验证。

## 内容概览

本书从 Hermes Agent 的运行机制出发，逐步介绍企业部署所需的基础设施、安全治理和工程实践。

- **基础与架构**：理解 Hermes Agent 的运行机制、安全边界及企业部署架构。
- **身份与隔离**：设计企业身份认证与授权机制，为员工的 Agent 提供独立的运行环境，并通过网络策略控制访问范围。
- **工具与权限治理**：通过 Tool Gateway 和 MCP 等机制接入企业系统，管理凭证、执行访问策略，并对高风险操作引入审批。
- **安全运营**：建立可观测性与审计机制，治理 Prompt Injection、Memory 和 Skills 等安全风险，并管理镜像供应链与平台生命周期。
- **端到端实践**：将前述组件组合起来，逐步搭建企业级 Hermes Agent 平台，并进行安全验收。
