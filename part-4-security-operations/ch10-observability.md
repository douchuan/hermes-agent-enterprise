# 第 10 章：建立 Agent 全链路可观测性与审计

> 状态：待撰写

## 本章目标

能够解释一次 Agent 执行发生了什么、为什么发生，以及哪些策略参与了决策。

## 建议内容

- 为什么传统应用日志不足以解释 Agent 行为
- 从用户请求到模型调用、工具执行和最终结果的 Trace
- OpenTelemetry 的 Trace、Metric 与 Log
- 统一关联 ID、员工 ID、Agent ID、工具调用 ID
- 记录策略判定、审批、拒绝与执行结果
- Token 用量、延迟、失败率和成本统计
- 敏感数据脱敏与审计数据访问控制
- 如何排查 Agent 为什么调用某个工具
- 运行日志、调试 Trace 与安全审计记录的区别

## 本章产出

- 可观测性架构
- 一次请求的完整 Trace 示例
- 审计事件模型
- 基础运营指标
