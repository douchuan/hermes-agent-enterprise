# 第 14 章：安全验收与生产部署检查清单

> 状态：待撰写

## 本章目标

提供可执行的验收标准，判断平台是否达到基本的企业部署要求。

## 验收项目

- [ ] Alice 和 Bob 的 Agent 运行环境及数据相互隔离
- [ ] 无法通过修改参数伪造身份或扩大工具权限
- [ ] Agent 无法绕过网络策略直接访问被禁止的外部目标
- [ ] Agent 无法读取不应访问的凭证
- [ ] Prompt Injection 无法直接突破工具授权边界
- [ ] 高风险操作可以被拦截、审批和追溯
- [ ] 审批不能被参数篡改或重复提交轻易绕过
- [ ] 员工离职后，相关访问权限可以被及时撤销
- [ ] 一次请求的模型调用、工具执行和策略判定可以关联
- [ ] 平台具备基本的容量监控、故障恢复和安全事件响应能力

## 本章产出

- 上线前检查清单
- 安全验收测试计划
- 已知风险与剩余风险说明
