# 第 13 章：从零搭建一个企业级 Hermes Agent 平台

> 状态：待撰写

## 本章目标

把前面章节的组件组合成一个可以演示、测试和继续扩展的参考项目。

## 实现里程碑

### 阶段 1：身份与入口

- Google 登录
- 企业成员校验
- 服务端会话
- 员工身份映射

### 阶段 2：个人 Agent Sandbox

- 由控制平面创建独立运行环境
- 独立工作目录与持久化数据
- 受限的工作负载身份
- Sandbox 生命周期管理

### 阶段 3：受控工具调用

- 通过 Tool Gateway 读取一个 GitHub Issue
- 验证调用方和员工身份
- 实施仓库与操作级授权

### 阶段 4：网络与凭证治理

- 限制直接出站访问
- 接入审计代理
- 避免向 Agent 暴露广泛的长期凭证
- 验证代理绕过会被阻断

### 阶段 5：审批、观测与验收

- 对写操作增加审批
- 展示完整 Trace
- 记录策略判定和执行结果
- 验证越权和代理绕过会被阻断
